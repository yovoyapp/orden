# Orden · Mente, Cuerpo, Espíritu

App web para ordenar el día en tres categorías:

- **Mente**: meditar, tomar aire fresco y entretenimiento sano (mínimo 10 min cada uno, con temporizador).
- **Cuerpo**: alimentación (desayuno, almuerzo, merienda y cena), descanso (mínimo 7 h) y ejercicio (mínimo 3 veces por semana).
- **Espíritu**: Biblia (mínimo 2 páginas), agradecer rezando y la iglesia (mínimo 1 vez por semana).

La pantalla principal muestra la hora, qué deberías estar haciendo según tus horarios fijos y cuánto falta para la próxima actividad. Los horarios se editan en ⚙︎ Ajustes.

Los datos se guardan en el navegador del dispositivo (localStorage). Usá **Exportar datos** en Ajustes para tener una copia.

## Publicarla con GitHub Pages

1. Creá un repositorio nuevo en GitHub (por ejemplo `orden`).
2. Subí todos estos archivos a la raíz del repositorio.
3. En el repo: **Settings → Pages → Branch: `main` / `(root)` → Save**.
4. En un minuto queda en `https://TU-USUARIO.github.io/orden/`.
5. Abrila desde el celular y elegí **"Agregar a pantalla de inicio"** para usarla como app.
